# 🧘 Nirvaha – AI-Powered Mental Health & Wellness Platform

An AI-powered holistic wellness platform that combines **Ancient Indian Wisdom (Ayurveda, Yoga & Meditation)** with **Modern Web Technologies** to promote mental health, mindfulness, and overall well-being. Built using **React + Vite**, Nirvaha offers personalized wellness guidance, Dosha analysis, AI-assisted conversations, breathing exercises, and wellness analytics in an immersive spiritual user experience.

# 📖 Overview

Mental health is an essential aspect of overall well-being. Nirvaha provides a personalized wellness experience by integrating Ayurvedic principles, guided breathing exercises, wellness tracking, and an AI-powered wellness assistant into a single platform.

Inspired by ancient Indian traditions, the application offers users a peaceful digital sanctuary where they can assess their mind-body constitution, practice daily wellness routines, receive AI-driven guidance, and monitor their personal wellness journey.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Rishith1705/Nirvaha.git
```

Navigate to the project

```bash
cd Nirvaha
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
